## 灰度标定流程

### 前置条件

- 八路模块已装车并确认通信正常
- 场地黑线已铺设
- 环境光照接近比赛条件

### 步骤 1：采集原始值

将传感器对准黑线和白底，分别记录 8 路的原始 ADC 值：

```
黑线：通道0=___ 通道1=___ 通道2=___ 通道3=___ 通道4=___ 通道5=___ 通道6=___ 通道7=___
白底：通道0=___ 通道1=___ 通道2=___ 通道3=___ 通道4=___ 通道5=___ 通道6=___ 通道7=___
```

### 步骤 2：计算归一化值

对每一路 i：

```
normalized_i = (raw_i - white_min_i) / (black_max_i - white_min_i)
```

- `black_max_i`：该路对准黑线时的最大原始值
- `white_min_i`：该路对准白底时的最小原始值
- 归一化后：1.0 = 黑线，0.0 = 白底

### 步骤 3：确定二值化阈值

默认阈值 0.5。如果光照不均匀导致某些通道临界值不稳定：

1. 沿黑线缓慢移动传感器
2. 记录每路的归一化值变化范围
3. 选择所有通道都能稳定区分黑白的阈值

### 步骤 4：验证偏差方向

1. 将传感器居中放在黑线上，确认 `compute_deviation()` 返回接近 0
2. 手动向右偏移，确认偏差变为正值
3. 手动向左偏移，确认偏差变为负值
4. 完全移出黑线，确认状态变为 LOST

### 步骤 5：调参

1. 初始参数：`kp=1.0, kd=0.1, vx_base=0.1`
2. 低速贴线运行，观察是否震荡
3. 震荡则降低 kp 或增大 kd
4. 响应迟钝则增大 kp
5. 逐步提高 vx_base，每次只调一个参数

### 步骤 6：记录标定结果

将最终参数写入 `robot.yaml`：

```yaml
line_follow:
  ros__parameters:
    kp: ___
    kd: ___
    vx_base: ___
    threshold: ___
    lost_threshold: 5
    edge_threshold: 0.3
    intersection_threshold: 6
```

同时在本文档记录标定日期、环境光照条件和测试结果。
