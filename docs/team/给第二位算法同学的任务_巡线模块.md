# 【任务：巡线偏差计算与纠偏控制器（robogame_core 纯算法模块）】

## 背景

- 场地规则有黑线连接启动区、材料区与搭建区，墙上另有 6 个视觉标签。当前仓库上下位机都**没有任何巡线代码**。
- 硬件侧：八路巡线模块只在照片盘点里出现过（`docs/field/REAL_CAR_HARDWARE_PRELIMINARY_INVENTORY_2026-08-09.md`），型号、接口、电平、是否装车**均未核验**——这部分由你与电控确认。
- 分工结论（已与算法一确认）：巡线 = **上位机决策控制**；你负责纯算法模块 + 场地/硬件数据，集成由算法一完成。

## 目的

在 `ros2_ws/src/robogame_core/robogame_core/` 新增 `line_follow.py`：把八路灰度传感器原始值转换为「横向偏差」和「纠偏输出」的纯函数，并配单元测试；同时交付灰度标定流程和场地黑线测量结果。

## 技术路线（参考 `navigation.py` 的纯函数风格）

1. 数据模型：`LineSegment`（起点/终点 Pose2D、线宽）、`LineSensorReading`（8 路 active 状态、加权中心）；
2. 偏差计算：8 路原始值 → 归一化横向偏差（-1..1），支持质心/加权平均两种方法；
3. 纠偏控制器：PD 或纯 P，输出机体坐标系 `vx/wz`（只输出纠偏量，不直接发 `cmd_vel`）；
4. 传感器状态机：`ON_LINE / LEFT_EDGE / RIGHT_EDGE / LOST`（出线连续 N 帧置 LOST）；
5. 单元测试（`tests/test_line_follow.py`，unittest 风格，参考 `tests/test_navigation.py`）：合成 8 路模式覆盖居中/左偏/右偏/出线/交叉口/无信号/全黑，验证偏差符号与方向一致；
6. 文档：算法说明、参数表（阈值、增益、LOST 帧数）、灰度标定流程。

## 不做（边界）

- 不写 ROS 节点、不发布话题；
- 不改 `motion_control/node.py`、`mission_manager`、`robot_bridge`；
- 不碰串口协议实现；「巡线遥测」协议字段由算法一与电控共同冻结后另行分配。

## 验收方法

- `python3 -m unittest tests.test_line_follow -v` 全部通过；
- 合成数据覆盖上述场景，偏差符号与方向正确；
- 交付标定流程文档 + 八路模块装车/接口确认结果（或未确认说明）。

## 证据边界

- 纯算法测试通过 ≠ 真车巡线验收，贴线精度需现场实测；
- 八路模块未经电控确认装车前，不视为可用硬件。

## 最小下一步

1. 与电控确认八路模块是否装车、接口电平、ADC 通道；
2. 同时开始写偏差计算纯函数。
