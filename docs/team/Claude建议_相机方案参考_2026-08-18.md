## 1. 原始建议内容（用户转述）

### 1.1 待拍板 #3 结案：不掉头

麦轮保持车头朝向、全向平移。

> 相机在前，车子不掉头，抓取的时候能看见，搭建的时候看不见，除非相机上机械臂。

### 1.2 C5 视觉倒塌检测：放置瞬间不成立 → 升级为最终方案

> C5 视觉倒塌检测在「放置瞬间」不成立 → 计时 + INCONCLUSIVE 从"短期兜底"升级为最终方案。这意味着 A4 里 P0-6 的 INCONCLUSIVE 处理必须做扎实，不能当临时代码写。
> 规则 3.2.2 S4 的 3s 稳定由裁判判定，我们不需要自己证明——但也就永远拿不到自证据。

### 1.3 「放置前视觉复核」划掉 → 层数上限按 2 层

> 「放置前视觉复核」从补偿手段里划掉 → 甲2 机构重复精度没有任何算法补偿了。
> 所以层数上限（待拍板 #4）的倾向是：按 2 层设计，不赌 3 层。等实测精度出来再决定要不要加第三层，而不是反过来。

### 1.4 否决「相机上机械臂」（eye-in-hand）

> 理由是它拿已经能工作的那一段去赌没工作的那一段：
> - eye-in-hand 要把图像坐标换算到车体坐标，必须知道每一刻相机在哪——也就是必须有臂的位置反馈。而没有位置反馈正是甲2 的根因。装上去的结果是抓取段的视觉对准也失效，而视觉对准是我们补底盘定位误差的主要手段，取存镖那 20 分靠它。
> - 换来的只有搭建段可见性，而它只服务两件事：倒塌自证（可以诚实标 INCONCLUSIVE）+ 放置复核（代价是少搭一层）。
> - 还是硬件改动，机械组当前状态做不了，会再拖时间。
> - 不要为了修没工作的部分而破坏已经工作的部分。
>
> 折中（后话）：如果将来臂有了位置反馈，还有个折中——臂只在几个标定过的离散姿态下拍照，每个姿态一套外参，不需要连续反馈。但这是后话。

### 1.5 好消息推断：按距离分段，不用转向

> 原方案是"单相机 + 定点转向拍标签"。但这四条事实指向一个更好的分段方式：按距离分段，不用转向。
> 相机前视俯下，看地面方块和看墙上 40cm 标签的矛盾只在近距离存在：
> - 站在 ~0.5m 抓取距离，要看地面方块得俯下 ~30°，墙上标签在视野外；
> - 站在 ~1.5m 外，地面方块只需俯 ~11°，40cm 标签约在水平上方 4°——两者可能同时落在同一视野内；
> - 任务流程本来就是"远处矫正位姿 → 靠近抓取"。如果成立，标签矫正和方块检测天然按距离互斥，一次转向都不用做。
>
> ⚠️ 这是基于"安装高度约 0.3m、垂直视场约 40–45°"的估算，不是事实。但它只要一张照片就能验证——相机装好后，在 1.5m 处拍一张同时含地面方块和墙上标签的图。这是甲3 相机安装最该先测的一件事，比量俯仰角更直接。

### 1.6 必须实测的一项（别假设）

> 撤退后建筑会不会重新回到视野？车头朝建筑、倒退离开，退到一定距离建筑可能重新可见。
> 如果是，倒塌检测的视觉方案在"释放后 3s 观察"这个窄窗口里仍然成立——而这正好是规则要的那 3 秒。
> 所以别急着把 C5 视觉方案整个划掉，只划掉"放置瞬间"那一段。

## 2.1 断链分析：对准 vs 复核（2026-08-18 补充）

Claude 建议划掉的是**复核**（放置后检查建筑稳不稳），但它没有回答一个更前置的问题：**相机看不见塔时，「第二层该放哪」怎么知道？**

| 动作 | 问的问题 | 看不见塔的影响 |
|---|---|---|
| **对准（align）** | 「第二层该放在哪？」→ 夹爪移到第一层塔顶正上方 | 严重——对准是放置的前置 |
| **复核（verify）** | 「刚才放得正不正？」 | 只是事后检查，靠它补偿不了对准错误 |

**看不见塔时，放第二层的对准只能靠开环定位链**：

```text
1. 车停在哪？        ← 里程计 + AprilTag + 巡线（车定位）
2. 塔顶在哪？        ← 第一层是我们放的，坐标已知 + 方块高度 0.1m
                       → 塔顶 = 第一层坐标 + 0.1m
3. 夹爪移到那        ← 车的位置 + 机械臂升降高度（车不动，只升降）
4. 释放
```

**误差逐层累积**：车停偏 2cm + 机构升降偏 1cm + 塔第一层放偏 1cm ≈ 第二层偏 4cm——方块只有 10cm 宽，偏 4cm 就悬空。

**「2 层」的真正理由**：不是「少搭一层省心」，而是**「第 3 层在看不见塔的前提下，开环误差几乎必然超标」**——第 1 层放地面（目标无限大）无碍；第 2 层要对准 10cm 塔顶吃全部定位误差；第 3 层再累积一次。

**可能的缓解（都需实测，别假设）**：
1. **放置前退一步看塔顶**：前进到放置位会被机械臂遮挡，但稍远位置塔顶可能可见（与 1.6 是同一物理事实的两面——远一点塔可见）。流程变「退 → 看塔顶 → 上前 → 放」，让第二层对准有闭环——这是「视觉复核」的变体，不是复核而是**对准**。
2. **靠场地规则性**：若塔须严格对齐场地标记（黑线/区域边），可用巡线/标签建立塔位置的强先验，减少对「第一层放得准」的依赖。
