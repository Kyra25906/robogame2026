# RoboGame 2026 一般场地图与状态切换基线

## 坐标与可信度

- 原点取全场外沿西南角；`+x` 沿 4.8 m 短边；`+y` 沿 7.2 m 长边指向对方半场；角度逆时针为正，`0 = 朝 +x`。
- **x 是短边方向（全场最大 4.8），y 是长边方向（全场最大 7.2）。** 填数据时不要弄反。
- 我方是红方，半场在西南角（启动区左下角 = (0.4, 0.4)）。
- `rule` 是规则文字明确给出的值；`estimated` 是按示意关系建立的首版位置；`unknown` 表示尚未测量；`measured` 才能用于厘米级停车和标签融合。区域尺寸和区域位置分别标可信度。
- 全场中心对称，因此对方（蓝方）可用 `(x, y, yaw) -> (4.8-x, 7.2-y, yaw+pi)` 从红方生成，最后把角度归一化。

## 已确定的地图骨架

规则确定：全场长边 7.2 m × 短边 4.8 m（含 0.4 m 黑色边界），黑线宽 0.05 m且允许 ±5%，启动区 0.6×0.6 m，搭建区 2.4×0.6 m（x方向/短边 2.4，y方向/长边 0.6），中央高台 1.8×1.7×0.2 m（x方向/短边 1.8，y方向/长边 1.7），斜坡 1.8×0.8 m约 14°。视觉标签每个 0.15×0.15 m，上沿高 0.4 m，所以中心高 0.325 m；现场确认全场 12 个 = 每半场 6 个（编号 1-6，各半场一套）。

图 3.8 给出半场巡线拓扑：启动区出线后进入一条横向主线；支线分别通向搭建区、屋顶材料区和墙体材料区。先按“路段拓扑”导航，不依赖示意图像素换算成的伪精确坐标。

## 定位与控制分工

1. 普通空旷路段：轮速里程计 + IMU，走 `WAYPOINT`。
2. 看见本段期望的黑线：切 `LINE_FOLLOW`，灰度阵列负责横向误差；里程计只负责沿线进度和防止走错支路。
3. 到标签交汇/作业点附近：识别到正确 ID 且 PnP 质量通过后切 `TAG_DOCK`；标签安装在现场黑色竖直挡板朝通道的一面，不按“外围/上/下墙”分类。标签只做绝对位置/姿态矫正，不用单帧结果直接控制高速运动。
4. 进入坡道区域或 pitch 越阈值：切 `RAMP`，限速并抑制里程计打滑影响。
5. 急停、通信丢失或定位无效：立即 `STOP`，优先级高于其他模式。

## 状态改变条件（首版）

| 当前 | 切换到 | 条件 | 失败处理 |
|---|---|---|---|
| WAYPOINT | LINE_FOLLOW | 路段要求巡线且连续看见黑线 | 5 帧丢线后停车搜索；仍丢失则回退低速路点 |
| LINE_FOLLOW | TAG_DOCK | 期望 ID 连续稳定出现且距离/斜视角通过门限 | 错 ID 不切换，只记日志 |
| 任意运动 | RAMP | 进入地图坡区或 IMU pitch 过阈值 | IMU 无效时按地图区低速通过 |
| TAG_DOCK | 作业状态 | 位置、航向连续稳定且机构就绪 | 超时退回对准点重试 |
| 作业状态 | RETREAT | 机构给出明确完成证据 | 无完成证据不得推进任务状态 |
| 任意 | STOP | 急停、心跳丢失、定位无效 | 人工复位后重新自检 |

## 只需现场精修的项目

## 现场数据回填对照表

坐标系（全场统一，和 `field_map.py` / `field_layout.yaml` 一致）：
原点 = 场地外沿西南角；`+x` = 沿 4.8 m 短边；`+y` = 沿 7.2 m 长边指向对方半场；角度弧度制，逆时针为正，`0 = 朝 +x`。
**x 是短边方向（0..4.8），y 是长边方向（0..7.2）。**

| 现场量的数据 | 填到哪个文件哪个字段 | 每个坐标是什么 |
|---|---|---|
| 标签 1–6 中心正下方地面点的位置和正面朝向 | `field_layout.yaml` → `visual_tags.anchors.1..6` 的 `x / y / yaw`；同步填 `field_map.py` → `tags` 字典 | `x`=沿短边方向离原点(m，0..4.8)；`y`=沿长边方向离原点(m，0..7.2)；`yaw`=正面法线指向（弧度，0=+x） |
| 各区域角点位置（启动区/搭建区/高台/材料区） | `field_map.py` → `default_field_map()` 里各 `Rect(x, y)`，并把 `position_confidence` 改成 `measured` | `x,y`=区域左下角坐标(m)；`width`=短边方向尺寸、`height`=长边方向尺寸，是规则值不要动 |
| 黑线起点/拐角/路口/终点 | `field_layout.yaml` → `survey.line_waypoints`（L01…），编号按行驶顺序 | 每个点 `x,y` + 类型 + 通向哪里 |
| 停车点（启动/抓取/搭建/撤退/坡前坡后） | `field_layout.yaml` → `survey.stops`（W01…） | 每个点 `x,y` + 车头朝向 `yaw` + 为什么停这里 |
| 坡道起止线 | `field_layout.yaml` → `survey.ramp_edges`（R01…） | 每个点 `x,y` + 说明 |
| 黑/白灰度值 | 巡线节点参数（不在本文件） | 每路"黑线均值/地面均值"取中间值作阈值 |
| 相机到车体外参 | 相机坐标变换（不在本文件） | 相机相对车中心的 x/y/z/偏角/俯仰 |
| 停车误差 | 到点容差/减速距离参数（不在本文件） | 命令距离 vs 实际位移 |

> 填完后的硬性校验：`field_map.py` 里所有坐标必须来自现场测量（`measured`）或规则文字（`rule`），
> 不允许"从示意图像素估"的 `estimated` 残留用于厘米级定位。跑 `tests/test_field_map.py` 确认尺寸/高度没被改坏。
