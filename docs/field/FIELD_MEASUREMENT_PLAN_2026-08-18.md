# 现场实测执行计划：D 阶段（2026-08-18 下午）

> 用途：打印带去现场，照着走、照着填。全部由算法组执行（电控/机械不来）。
> 回填：回到住处后把数据填入 `robot_field.yaml` / 新标签映射 yaml / 执行队列 D1-D6。
> 关联：执行队列阶段 D；`FIELD_DAY1_EXECUTION_ORDER.md`（E 阶段用，本文件只做测量）。

---

## 0. 出发前准备（5 分钟）

**带**：卷尺（≥5m）、胶带/粉笔（标原点）、手机（记录 + 拍照）、纸笔或手机备忘录、本计划打印件。

**⚠️ 第一件事：定坐标系（错一步全错，全场统一）**

- 原点：选场地**某个角**（问裁判或看场地标注，固定下来，贴胶带标记）
- +x：沿场地**长边**，从原点指向对方半场
- +y：沿场地**短边**
- 单位：米；角度现场记「朝哪边」，回来换算 `弧度 = 角度 × 3.14 ÷ 180`

> 这个坐标系必须和 D1 航点、D2 标签、C6 半场边界用**同一个**。到场先确认场地朝向，别猜。

**优先级**（时间不够砍后面的）：D2 标签(含样式) > D1 航点 > D3 黑线 > D6 撤退 > D5 机构 > D4 IMU

## 1. D1 场地航点实测（4 个点）

**走法**：原点 → 启动区 → （沿黑线）→ 材料区 → 搭建区 → 撤退点

**每个点怎么量**：
1. 站在该位置（车头朝的方向 = 你面对的方向）
2. 卷尺一头放原点，沿长边拉 = x；沿短边拉 = y
3. 记朝向：朝长边=0° / 朝短边=90° / 斜的估
4. 拍照：原点 + 尺子 + 目标点同框

**记录表**：

| 点 | x (m) | y (m) | 朝向 (°) | 备注 |
|---|---|---|---|---|
| 启动区 | | | | 车头朝哪 |
| 材料区 | | | | **量水平投影**，别量斜坡长度 |
| 搭建区 | | | | |
| 撤退点 | | | | 离搭建区约 0.3–0.5 m |

## 2. D2 AprilTag 坐标映射表（6 个标签）—— 最优先

**⚠️ 先做一步（10 秒）**：看标签实物是**黑白方格码**还是**带数字的牌子**，**每个拍一张近照**。
（决定 C2 检测器要不要改；仓库样例检测不到标准 AprilTag，疑似数字牌）

**每个标签怎么量**：
1. 看标签上的数字/图案 → 记 id（1~6 哪个）
2. 量标签**中心正下方地面点**的 (x, y)
3. 量离地高度（标签中心到地面，米）
4. 量朝向：站在标签**正面**，你视线方向在场地坐标系朝哪（长边=0° / 短边=90°）

## 3. D3 黑线路径（不是手画，是沿线量点）

黑线**已经在场地上**（胶带/油漆），你要做的是**把它的位置记下来**：

1. 沿黑线走，**每 0.5 m 停一下**
2. 卷尺从原点量该点 (x, y)
3. 记在表里（尽量多记，回来连成折线 = C4 巡线路径）

**记录表**（不够就加行）：

| 点 | x (m) | y (m) |
|---|---|---|

| 2 | | |
| 3 | | |
| 4 | | |

**灰度阈值**（若红外模块已装车）：车放黑线上读一次、白地上读一次，阈值 = 两者中间。没装车就记「待装车后测」。

## 4. D4 IMU 状态确认（大概率测不了，只确认）

1. 上车看 `ros2 topic echo /robot/status` 的 `imu_valid`
   - 还是 `false` → IMU 未接入，**记「未接入」**，D4 测不了
   - `true` → 车静止看角速度均值（零偏）、车头转 90° 看输出（轴向）、翘起看 pitch

**记录**：`imu_valid` 现状 = ____ ；测得数据 = ____

---

## 5. D5 机构状态确认（依赖电控 0x20 执行层）

- 若机构能动：用 `tools/mechanism_acceptance.py` 逐个测 GRAB/LIFT/RELEASE/HOME，记录行程/耗时/重复精度（各 10 次）
- 若机构不能动（0x20 还是 ACK_BAD_STATE）：**记「机构不可动，需电控交付 0x20 执行层」**——这是硬件依赖，不是欠账

**记录**：机构能动吗？____ ；实测参数 = ____ 或「不可动」

---

## 6. D6 撤退参数（依赖限幅）

- 若限幅已开（车能自主动）：发撤退导航，量「命令撤退 0.3 m → 实际停哪」→ 停车精度
- 若限幅没开：**记「待限幅开通后测」**

**记录**：命令距离 = ____ ；实际位移 = ____ ；停车误差 = ____

## 现场三坑提醒

1. **坐标系没定就开量** → 数据作废。先定原点 + 朝向再开始。
2. **标签样式没拍照** → C2 检测器没法确认。每个标签拍近照。
3. **材料区量了斜坡长度** → 错。量水平投影（俯视 x/y）。
