# 给机械组：待确认清单

> 用途：算法组完成「真车对接」前，还需要机械组补齐的物理参数与动作语义。
> 单位统一用 毫米(mm)/牛顿(N)/秒(s)/度(°)。不知道的请填「未知，待实测」，不要猜。
> 依赖关系：机械参数先冻结 → 电控才能定义字节编码 → 软件才能写解码器。
