# 第 2 课：让机器人先“看见”方块

这一课只探索 `cube_perception`。目标不是马上接相机，而是先回答一个最小问题：给程序一张确定的图片，它能否找出橙色和紫色方块，并拒绝把一次偶然闪现直接交给控制模块？

## 输入、处理、输出

输入是一张由程序生成的 320×240 图片：黑色背景，左边一个橙色方块，右边一个紫色方块。颜色直接在 HSV 空间指定，所以不受显示器色差影响。

处理分两步：

1. `CubeDetector.detect()` 把 BGR 图片转成 HSV，按橙/紫阈值生成二值掩膜，做形态学去噪，寻找轮廓，经过面积和形状过滤，然后估算置信度、距离、横向偏移与像素中心。
2. `TemporalDetectionFilter.update()` 追踪相邻帧中的同色目标。默认必须连续出现 3 帧，才输出“已确认”目标。

输出包括终端 JSON，以及 `output` 目录中的原图、两张颜色掩膜、标注图和 `result.json`。预期现象是：单帧立即找到橙、紫两个候选；第 1、2 帧确认列表为空；第 3 帧同时确认两种颜色。

## 运行

在本目录执行：

```powershell
python experiment.py
```

如果原项目不在默认位置：

```powershell
python experiment.py --project D:\your\path\xu
```

看到最后一行“实验通过”即完成。打开 `output/scene.png` 和两张 `*_mask.png` 对照：原图中的目标在对应掩膜里应为白色，其余区域为黑色。

## 这一课真正学到什么

- 掩膜回答“哪些像素颜色像目标”。
- 轮廓和形状过滤回答“这些像素是否组成一个像方块的物体”。
- 针孔模型用 `距离 ≈ 焦距像素 × 方块真实边长 ÷ 图中边长像素` 给出粗距离。
- 连续帧确认回答“它是否稳定存在”，防止单帧噪声触发机器人动作。

合成图通过只说明算法管线接通，不代表现场已经可靠。真实相机还要重新调 HSV、曝光、ROI 和焦距参数。
